# MTGNP Desktop GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a polished Tkinter client that exposes the existing two-player protocol and renders the 58 supplied cards with bundled local images.

**Architecture:** Keep `ClientNetwork`, `ClientStateStore`, and `ClientController` presentation-neutral. A GUI event bridge moves network callbacks onto Tk's main thread; a pure view-model module derives display data; the Tkinter adapter renders that data and sends every action through `ClientController`.

**Tech Stack:** Python 3.12, standard-library Tkinter/ttk, unittest, Scryfall used only to acquire development-time image assets.

## Global Constraints

- No runtime web requests, API keys, or non-standard Python dependency.
- Preserve terminal-client behavior and server authority.
- Include optimized full-card PNGs for the 58 supplied exact card names, with attribution; do not include original-resolution downloads.
- Do not commit or push implementation or planning artifacts during this task.
